# Compasso

A trilha do sim em arquivo único (`index.html`). 20 referências com intenção, filtros por momento, estilo e clima, favoritas, roteiro da cerimônia com exportação e assistente.

Produção: https://compasso-casamentos-production.up.railway.app

Deploy: Railway, projeto `compasso-casamentos`, serviço ligado ao repo com Dockerfile nginx na porta 8080.

```powershell
python -m http.server 8000
```
